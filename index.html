Projects

Cayo’s Kitchen

Learning project · 3D cooking game

  • Unity
  • C#
  • Input System
  • ScriptableObjects
  • Built player movement with capsule-cast collision that slides along walls, plus raycast-based counter selection and interaction using Unity’s Input System.
  • Structured interactions with inheritance and interfaces: one base counter class with seven counter types (clear, container, cutting, stove, plate, delivery, trash).
  • Coded cooking mechanics: chopping with progress bars, and a stove that moves food through idle, frying, fried and burned states on timers.
  • Used ScriptableObjects to define ingredients and cutting, frying and burning recipes, keeping game data separate from code.
  • Built an order system that spawns random recipes on a timer and checks delivered plates against them, with the UI updated through C# events.
